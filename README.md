# Parnasocial

Parnasocial is a simple desktop media player for Windows built with [Electron](https://www.electronjs.org/).

## Features

- Modern desktop user interface with native Windows 11 style title bar controls
- Playback controls (play, pause, next, previous, volume slider)
- Folder and playlist navigation
- Light and dark theme switching

## Requirements

- Windows 10 / 11 (x64)
- Node.js >= 20.0.0
- npm >= 10.0.0

## Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/vexikoff/parnasocial.git
   cd parnasocial
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run in development mode:
   ```bash
   npm start
   ```

4. Build distributable Windows packages:
   ```bash
   npm run dist:win
   ```
